title: Keyboard shortcuts
description: Every keyboard shortcut in mail, calendar, drive and the workflow editor, the shortcuts for search and for switching workspaces, and the keys inside the search window.
---

Mail, calendar, drive and the workflow editor each have their own shortcuts. Most of them are two keys pressed one after the other: a prefix letter for the section, then a second key.

## How shortcuts work

- **Press the prefix, then the key.** Press **m** in mail, **c** in calendar, **d** in drive or **w** in the workflow editor, then press the second key within about 1.5 seconds. For example, **m** then **i** opens the inbox. While the prefix is active, a hint shows the keys you can press.
- **A wrong second key does nothing.** If you press the prefix and then a key with no shortcut, nothing happens.
- **Mail, calendar, drive and workflow shortcuts pause while you type.** They do nothing while you are typing in a field, such as a search box or the message editor. Switching workspaces with **Alt** and a number still works.
- **Press ? for help.** In mail, calendar, drive and the workflow editor, **?** shows or hides the **Keyboard shortcuts** dialog for that section. Press **Esc** or click **Close** to close it.
- **Press Ctrl + K to search.** Workspace search also finds commands such as **Compose mail** and settings pages, so you can run them by typing their name. See [Search](#search).

## Everywhere

| Keys                                           | Action                                                            |
| ---------------------------------------------- | ----------------------------------------------------------------- |
| **Alt** + **1** to **9** (**Option** on a Mac) | Switch to the 1st to 9th workspace, in the order of the left rail |

Switching workspaces works on any page and with any keyboard layout. It does nothing if you also hold Ctrl, Cmd or Shift. The help dialog has a list of workspaces only when you belong to more than one. It lists only your first five, but **Alt** with **6** to **9** works too.

## Search

| Keys                                      | Action                |
| ----------------------------------------- | --------------------- |
| **Ctrl** + **K** (**⌘** + **K** on a Mac) | Open workspace search |

The search shortcut works on every page of a workspace, including its settings. It does nothing while you are typing in a field or in the message editor, and it does not work on your account settings or the instance dashboard. See [Search your workspace](/guide/search/search-your-workspace).

Inside the search window:

| Keys                                              | Action                                                                                                                                                                                |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Up** and **Down** arrows                        | Move through the results, or through the actions when the list of actions is open. The list wraps around at the ends.                                                                 |
| **Enter**                                         | Pick the highlighted suggestion, show more results on **Load more**, or run the first action of the highlighted result. When the list of actions is open, run the highlighted action. |
| **Tab**                                           | Pick the highlighted suggestion, or the first one. With no suggestions, open the list of actions for the highlighted result.                                                          |
| **Right arrow**                                   | Open the list of actions, when the cursor is at the end of the search box                                                                                                             |
| **Ctrl** + **Enter** (**⌘** + **Enter** on a Mac) | Open the list of actions for the highlighted result                                                                                                                                   |
| **Esc**                                           | Go back from the list of actions to the results. Otherwise, close search.                                                                                                             |
| **Home** and **End**                              | Move the cursor to the start or the end of the search box                                                                                                                             |

## Mail

Press **m**, then:

| Keys             | Action                                                                                                                                                                                       |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **m** then **i** | Go to Inbox                                                                                                                                                                                  |
| **m** then **s** | Go to Sent                                                                                                                                                                                   |
| **m** then **d** | Go to Drafts                                                                                                                                                                                 |
| **m** then **f** | Go to Starred                                                                                                                                                                                |
| **m** then **t** | Go to Trash                                                                                                                                                                                  |
| **m** then **v** | Go to Archive                                                                                                                                                                                |
| **m** then **p** | Go to Spam                                                                                                                                                                                   |
| **m** then **c** | Compose a new message                                                                                                                                                                        |
| **m** then **r** | When a message is open, opens a new blank message. It does not fill in a reply. To reply, use the **Reply** bar at the bottom of the reading pane.                                           |
| **m** then **x** | Star or unstar the open message                                                                                                                                                              |
| **m** then **u** | Mark the open message read or unread                                                                                                                                                         |
| **m** then **e** | Archive the open message                                                                                                                                                                     |
| **m** then **#** | Delete the open message, without asking first. Most mailboxes move it to Trash; Cloudflare Email and Resend mailboxes, and messages already in Trash on a mail server, are deleted for good. |
| **m** then **/** | Jump to the search box                                                                                                                                                                       |
| **m** then **a** | Open or close the **Mail AI** panel                                                                                                                                                          |

Without a prefix:

| Keys           | Action                                                  |
| -------------- | ------------------------------------------------------- |
| **j** or **n** | Open the next message in the list, and mark it read     |
| **k** or **p** | Open the previous message in the list, and mark it read |
| **Esc**        | Close the message editor, or the help dialog            |

## Calendar

Press **c**, then:

| Keys             | Action                                    |
| ---------------- | ----------------------------------------- |
| **c** then **d** | Day view                                  |
| **c** then **w** | Week view                                 |
| **c** then **m** | Month view                                |
| **c** then **y** | Year view                                 |
| **c** then **s** | Schedule view                             |
| **c** then **t** | Go to today                               |
| **c** then **n** | New event, starting at the next full hour |
| **c** then **r** | Refresh the calendar                      |
| **c** then **a** | Open or close the **Calendar AI** panel   |

Without a prefix:

| Keys           | Action                                               |
| -------------- | ---------------------------------------------------- |
| **j** or **n** | Next day, week, month or year, depending on the view |
| **k** or **p** | Previous day, week, month or year                    |

## Drive

Press **d**, then:

| Keys             | Action                               |
| ---------------- | ------------------------------------ |
| **d** then **n** | New folder                           |
| **d** then **u** | Upload files                         |
| **d** then **s** | Jump to the search box               |
| **d** then **l** | List view                            |
| **d** then **g** | Grid view                            |
| **d** then **r** | Go to the top of the drive           |
| **d** then **h** | Go to All drives                     |
| **d** then **p** | Preview the selected file            |
| **d** then **a** | Open or close the **Drive AI** panel |

Without a prefix:

| Keys           | Action                                         |
| -------------- | ---------------------------------------------- |
| **j** or **n** | Go forward to the next folder in your history  |
| **k** or **p** | Go back to the previous folder in your history |

In drive, **j** and **k** move through the folders you have visited, like a browser's back and forward buttons. They do not move a selection. Your history is kept when you switch between drives.

## Workflows

These work in the workflow editor. See [Workflows](/guide/workflows).

Press **w**, then:

| Keys             | Action                                                                                                                                                        |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **w** then **a** | Open the **Add step** window                                                                                                                                  |
| **w** then **l** | Tidy up the layout                                                                                                                                            |
| **w** then **t** | Open the **Test run** tab                                                                                                                                     |
| **w** then **r** | Run the saved workflow now. If its **Run by hand** trigger asks for inputs, this opens the inputs dialog first. It does nothing for a workflow not yet saved. |

Without a prefix:

| Keys                                                              | Action                                                      |
| ----------------------------------------------------------------- | ----------------------------------------------------------- |
| **Ctrl** + **S** (**⌘** + **S** on a Mac)                         | Save                                                        |
| **Ctrl** + **Z** (**⌘** + **Z** on a Mac)                         | Undo                                                        |
| **Ctrl** + **Shift** + **Z** (**⌘** + **Shift** + **Z** on a Mac) | Redo. **Ctrl** + **Y** (**⌘** + **Y** on a Mac) also works. |
| **Ctrl** + **C** (**⌘** + **C** on a Mac)                         | Copy the selected steps                                     |
| **Ctrl** + **V** (**⌘** + **V** on a Mac)                         | Paste steps                                                 |
| **Ctrl** + **D** (**⌘** + **D** on a Mac)                         | Duplicate the selected steps                                |
| **Delete** or **Backspace**                                       | Remove the selected steps or connections                    |
| **?**                                                             | Show or hide the **Keyboard shortcuts** dialog              |

**Ctrl** + **S** saves even while you are typing in a field. The other keys do nothing while you type. The **Keyboard shortcuts** dialog is also in the editor's **More workflow actions** menu (**...**).
