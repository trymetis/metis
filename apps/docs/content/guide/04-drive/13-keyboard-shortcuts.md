---
title: Keyboard shortcuts
description: Every keyboard shortcut you can use in Drive.
---

Most Drive shortcuts are two keys pressed one after the other: first <kbd>d</kbd>, then a second key. After you press <kbd>d</kbd>, a hint with the possible keys shows for a moment. A key that is not in the list does nothing.

Shortcuts do not work while you are typing in a box, such as the search box.

## Drive shortcuts

| Keys                           | What it does                                    |
| ------------------------------ | ----------------------------------------------- |
| <kbd>d</kbd> then <kbd>n</kbd> | New folder                                      |
| <kbd>d</kbd> then <kbd>u</kbd> | Upload                                          |
| <kbd>d</kbd> then <kbd>s</kbd> | Go to the search box                            |
| <kbd>d</kbd> then <kbd>l</kbd> | List view                                       |
| <kbd>d</kbd> then <kbd>g</kbd> | Grid view                                       |
| <kbd>d</kbd> then <kbd>r</kbd> | Go to the top of the drive                      |
| <kbd>d</kbd> then <kbd>h</kbd> | Go to [All drives](/guide/drive/all-drives)     |
| <kbd>d</kbd> then <kbd>p</kbd> | Preview the selected file                       |
| <kbd>d</kbd> then <kbd>a</kbd> | Open or close [Drive AI](/guide/drive/drive-ai) |

## Single keys

| Keys                                          | What it does                                                         |
| --------------------------------------------- | -------------------------------------------------------------------- |
| <kbd>k</kbd> or <kbd>p</kbd>                  | Back to the previous folder you visited                              |
| <kbd>j</kbd> or <kbd>n</kbd>                  | Forward again                                                        |
| <kbd>?</kbd>                                  | Show or hide the **Keyboard shortcuts** help                         |
| <kbd>Alt</kbd> + <kbd>1</kbd> to <kbd>9</kbd> | Switch to your first to ninth workspace (<kbd>Option</kbd> on a Mac) |

Back and forward walk through the folders you visited, like the back and forward buttons of a browser. They do not move the selection. The history stays when you switch to another drive, so <kbd>k</kbd> can take you back to a folder in the drive you came from.
