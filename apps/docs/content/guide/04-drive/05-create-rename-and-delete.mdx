---
title: Create, rename and delete
description: Make new folders, rename files and folders, and know when a deleted item can be restored.
---

These actions change your files at the provider, so the change shows everywhere you use that drive.

## Create a folder

1. Open the folder where the new folder should go.
2. Click **New folder** in the toolbar, or press <kbd>d</kbd> then <kbd>n</kbd>.
3. In the **New folder** dialog, type a name in **Name**.
4. Click **Create**, or press <kbd>Enter</kbd>.

If the folder cannot be made, you see "Could not create that folder".

## Rename a file or folder

1. Click the **...** button on the item, or right-click it.
2. Choose **Rename**.
3. The **Rename** dialog shows the current name. Change it.
4. Click **Rename**.

## Delete a file or folder

1. Click the **...** button on the item, or right-click it.
2. Choose **Delete**.
3. Read the message in the dialog, then click **Delete**, or **Cancel** to keep the item.

What happens next depends on the drive type:

| Drive type                          | What Delete does                                                                | The dialog says                                                                   |
| ----------------------------------- | ------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Google Drive, OneDrive              | Moves the item to the trash of the connected account. You can restore it there. | "It moves to the trash of the connected account, where it can still be restored." |
| S3 storage, WebDAV, FTP, FTPS, SFTP | Deletes the item for good.                                                      | "It is deleted permanently. This can't be undone."                                |

:::warning[No trash on storage servers]
On S3, WebDAV, FTP, FTPS and SFTP drives there is no trash. A deleted file or folder cannot be brought back from Metis.
:::

## Moving files

The file list has no move action. To move a file to another folder in the same drive, ask [Drive AI](/guide/drive/drive-ai). Files cannot be moved from one drive to another.
