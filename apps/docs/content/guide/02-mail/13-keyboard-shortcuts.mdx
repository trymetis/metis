---
title: Keyboard shortcuts for mail
description: Move around mail and act on messages without the mouse.
---

Mail shortcuts use the letter **m** first. Press **m**, then the second key within about a second and a half. While **m** is waiting for the next key, a bar at the bottom of the screen lists every choice.

Shortcuts do nothing while you are typing in a field, such as the search box or the composer.

## m shortcuts

### Go to a folder

| Keys             | Goes to |
| ---------------- | ------- |
| **m** then **i** | Inbox   |
| **m** then **s** | Sent    |
| **m** then **d** | Drafts  |
| **m** then **f** | Starred |
| **m** then **t** | Trash   |
| **m** then **v** | Archive |
| **m** then **p** | Spam    |

### Act on mail

| Keys             | What it does                                                                                                                     |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **m** then **c** | Opens a new message.                                                                                                             |
| **m** then **r** | With a message open, opens a new, empty message, not a reply. To reply, use the **Reply** bar at the bottom of the reading pane. |
| **m** then **x** | Stars or unstars the open message.                                                                                               |
| **m** then **u** | Marks the open message as read or unread.                                                                                        |
| **m** then **e** | Archives the open message.                                                                                                       |
| **m** then **#** | Deletes the open message, without asking first.                                                                                  |
| **m** then **/** | Jumps to the search box.                                                                                                         |
| **m** then **a** | Opens or closes the Mail AI panel.                                                                                               |

:::warning
**m** then **#** moves the message to **Trash** at once, with no confirmation. You can restore it from Trash.
:::

## Single keys

| Key            | What it does                                                                                   |
| -------------- | ---------------------------------------------------------------------------------------------- |
| **j** or **n** | Opens the next message in the list and marks it read in your mailbox, like clicking a row.     |
| **k** or **p** | Opens the previous message in the list and marks it read in your mailbox, like clicking a row. |
| **?**          | Shows or hides the **Keyboard shortcuts** help.                                                |
| **Esc**        | Closes the composer, or the shortcuts help.                                                    |

**j**, **n**, **k** and **p** move one message at a time, not one row at a time. They step through every message the current list has loaded:

- On most tabs, every message the folder has loaded, including the ones the tab hides (for example on **Primary** and the label tabs) and muted conversations in the Inbox.
- On **Unread** and **Starred**, that list, including messages you have since read or unstarred.
- On a label filter, the messages with that label, including muted conversations.
- During a search, the search results, including the ones the tab hides.
- On **Read later**, the messages you saved.

They also stop on the earlier messages of a conversation, not only the latest one. With no message open, **j** and **k** open the first message. At either end of the list, they stay where they are. **Prev** and **Next** in the toolbar step only through the rows you can see.

**j**, **n**, **k** and **p** do nothing while you hold Ctrl, Cmd, Alt or Shift.
