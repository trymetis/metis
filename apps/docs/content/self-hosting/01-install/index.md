title: Install
description: Check what your server needs, deploy Metis Suite, create the owner account and serve it over HTTPS.
---

Most operators install Metis Suite with the bootstrap script. It sets up Docker, writes the settings file, and starts every service for you. With the bootstrap script or Docker Compose, read Requirements first, then your install page, then First run. On a container platform, on Vercel or on another Node host, go straight to that page: it lists what you need. Then continue with First run.

- [Requirements](/self-hosting/install/requirements): what the server needs for the bootstrap script or Docker Compose.
- [Install with the bootstrap script](/self-hosting/install/install-with-bootstrap): deploy the whole stack with one command.
- [Install with Docker Compose](/self-hosting/install/install-with-docker-compose): run the stack yourself, without the script.
- [Deploy on a container platform](/self-hosting/install/deploy-on-a-container-platform): run the published images on Railway, Render, Fly.io, Google Cloud Run, Kubernetes or another container host.
- [Deploy on Vercel or another Node host](/self-hosting/install/deploy-on-vercel): build the app from its source code.
- [First run](/self-hosting/install/first-run): use the setup code to create the owner account.
- [Domain and HTTPS](/self-hosting/install/domain-and-https): serve a bootstrap or Docker Compose install on your own domain with a certificate. Container platforms and Vercel handle HTTPS themselves.
