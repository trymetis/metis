title: Install

Most operators install Metis Suite on a Linux server with the `metis` CLI, a command-line tool that installs Docker, writes the settings file and starts everything for you. Read Requirements first, then the install page, then First run. On a container platform, on Vercel or on another Node host, go straight to that page: it lists what you need. Then continue with First run.

- [Requirements](/self-hosting/install/requirements): what a server needs for the `metis` CLI.
- [Install with the metis CLI](/self-hosting/install/install-with-bootstrap): install Metis Suite on a Linux server with one command.
- [Deploy on a container platform](/self-hosting/install/deploy-on-a-container-platform): run the published images on Railway, Render, Fly.io, Google Cloud Run, Kubernetes or another container host.
- [Deploy on Vercel or another Node host](/self-hosting/install/deploy-on-vercel): build the app from its source code.
- [First run](/self-hosting/install/first-run): use the setup code to create the owner account.
- [Domain and HTTPS](/self-hosting/install/domain-and-https): serve a server the `metis` CLI runs on your own domain with a certificate. Container platforms and Vercel handle HTTPS themselves.
